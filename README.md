https://github.com/camdenslade/EvenApp. [MOVED TO PRIVATE REPO]
- This is my first time working with React Native and I chose to use Expo so that I would be able to test my application on IOS using Expo Go since I do not operate in a MacOS environment. The concept is fairly similar to Tinder but an attempt is going to be made to implement a fair ratings system so that users can leave feedback or "reviews" that will only be available to the reviewer and reviewee. Additionally, the sum of their scores 1-10 will be summed and display on their profile with an occasional check of the population's total avarage per sex. If this check is less than 5.0, every user of that sex's rating will be adjusted so that the average becomes 5.0 as to not skew the data by human nature. As for the card stack, for straight individuals, swiping left or right simply skips the user and holding down on a button in the bottom middle of the screen sends a like. For users looking for anyone, swiping right will shuffle through the male card stack and swiping right will shuffle through the female. I will also implement a paid feature to search for a first name within say a 25 mile radius if a user so chooses to do that. Each user will get three reviews per week with the first and third being between 3-10 and the second between 5-10. Each review must be used to unlock the next one. For cases of domestic/sexual abuse each user will have an emergency lifetime review that can go 1-10 or a user can also select between 1-3 if they choose to report the individual. A user can only submit a review once each user has sent at least two messages in the chat. The aim of this application is to create an Even dating environment that integrates elements of Tinder and the Tea app in their best forms. IOS development will come soon once I scrape together the funds to join the Apple Developer Platform, but until then I will only support Android and a temporary web app as I am just a student. This application is in the early stages of development.
